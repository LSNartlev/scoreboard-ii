# Scoreboard II - Made with LÖVE
Lua/LÖVE-based Scoreboard for Basketball, Volleyball, and other net sports

created by LSNartlev

## Features
- Operate the Scoreboard using:
  - Keyboard
  - Mouse
  - Controller
- Team customization:
  - Aside from the team name, background and text colors can be customized according to the teams' official colors. Can save up to 64 preset teams.
  - Customizable period/shot clock setup and mechanics for basketball (WIP)
  - Customizable set point requirement(s) for volleyball, badminton, table tennis, and pickleball (WIP)
- Supports custom sound effects**

  ** With the exception of the horn buzzer, other sound effects not included. Subject to file formats supported by LÖVE framework.
